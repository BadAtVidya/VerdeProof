# Preprod Onboarding Script

Send this script to each launch user:

1. Install the 1AM browser wallet.
2. Select **Midnight preprod**.
3. Fund the wallet with Preprod tDUST.
4. Open https://verde-proof.vercel.app/ and choose **Open console**.
5. Connect 1AM and approve the Preprod connection.
6. Set a test recycled-content threshold.
7. Review the requirement and approve the transaction.
8. Wait for indexer propagation, then open **Public verifier**.
9. Send back only the public Preprod wallet address and transaction link/hash.

Never send seed phrases, private keys, passwords, raw laboratory reports, or personal documents. Use test data only.
